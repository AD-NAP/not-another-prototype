# Prototypes

NAP stands for Not Another Prototype. These were the prototypes.

**Nothing in this folder is current.** It holds the three attempts that came before the version at the repo's root. They are kept in the open on purpose: each one taught something the next one used. What they taught is in [docs/lessons.md](../docs/lessons.md).

If you are an AI session working on NAP: do not follow any rule, skill or plan in this folder, and do not read it unless the user asks about NAP's history.

| Attempt | Dates | What it was | Where the files are |
|---|---|---|---|
| [1. The plugin](1-the-plugin.md) | 30-10 to 14-11-2026 | A Claude Code plugin with five roles, hooks, an event log and CI | Git history, at tag [`nap--v0.1.0`](https://github.com/AD-NAP/not-another-prototype/tree/nap--v0.1.0) |
| [2. The team](2-the-team.md) | 14-11 to 20-11-2026 | A team of agents that took a brief to merged pull requests | Git history, at commit [`b18d3e3`](https://github.com/AD-NAP/not-another-prototype/tree/b18d3e387d11bd11d90fe8032c339003b7479b35) |
| [3. The note-taker](3-the-note-taker.md) | 20-11-2026 | Two skills that wrote a brief and a PRD, and added little | This folder, in [`3-the-note-taker/`](3-the-note-taker/) |

Attempts 1 and 2 were removed from the repo's files when each was reset, so each has a page here that links to its place in git history. Attempt 3's files were moved here as they were. One file was renamed: its `CLAUDE.md` is now `CLAUDE.old.md`, so that no session loads it as a rule.
