# Roadmap

Start small. Each step works on its own and can be shown, so the project is never stuck half done.

The phase-by-phase todo list for steps 6 to 9, with versions, is in [todo.md](todo.md). **Step 9 ends in v1.0.0, the MVP.**

The sprint loop comes before Sprint 0. The sprint loop is what turns plans into working software, and NAP can use it on itself right away, because NAP's own foundational docs already exist (this folder). The MVP is the loop made reliable, set up in one command, chained by a Chief of Staff skill, and proven on a second project. Sprint ceremonies and the Sprint 0 roles follow the MVP.

Steps 6 onward were reordered on 2026-11-14 (see [decision 18](decisions.md#18-the-mvp-is-the-loop-setup-a-chief-of-staff-skill-and-proof-2026-11-14)). Older decisions use the old numbers: old 6 is now 10, old 7 is 9, old 8 is 11, old 9 is 12, old 10 is 7, old 11 is 13, old 12 is 8 and 14, old 13 to 15 are 15 to 17.

## Open questions

- Where agents run on their own: GitHub Actions, Claude cloud sessions, or the user's machine.
- Budget: a token cap per project or per agent.
- How velocity is measured: issues per window, or something closer to token cost.
